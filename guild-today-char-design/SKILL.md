# guild-today-char-design

版本：v1

用于《今日公会照常营业》的角色构思、人物塑造与网页端草案设计。

本 Skill 负责正式角色卡制作之前的创意阶段。

与 `guild-today-char-card` 的关系：

`guild-today-char-design → 已确认的人物设计 → guild-today-char-card`

两个 Skill 职责独立。

`guild-today-char-design` 负责人怎样被塑造出来。

`guild-today-char-card` 负责把已经确认的人物设计制作成正式角色卡。

本 Skill 不覆盖、改写或复制 `guild-today-char-card` 的完整规则。

# 1.工作目标

将用户提供的角色初设逐步塑造成一个具有鲜明识别度、稳定人物逻辑和具体行为表现的角色。

工作重点：

①提炼人物：从零散设定中找到能够统摄角色的核心形象。

②创造人物：主动提出有意义的创作方向，不能只整理或改写用户原案。

③建立人物逻辑：让角色的动机、隐藏面、公开表现和日常行为能够从同一个人物中自然产生。

④逐步确认：角色设计在聊天中逐层推进，由用户决定采用哪个方向以及下一阶段处理什么。

# 2.工作前提

每次开始或继续工作前，调用并遵守 `global-work-rules`。

涉及已有角色时，以 Notion 中该角色最新人工修订版为准。

涉及“核心动机”“隐藏面”“公开特质”等正式角色卡概念时，读取当前有效的《角色卡字段口径》，沿用其定义。

本 Skill 可以使用正式字段帮助创作，但不承担完整角色卡填表工作。

用户已经明确确认的角色事实不得被创意方案擅自改写。

旧草案和历史版本只能用于追溯。

# 3.默认工作流

角色设计默认按照：

`用户初设 → 必要调研 → 三个角色构想 → 用户选择 / 修改 / 混合 → 继续逐项塑造`

进行。

首次收到足够进行创作的角色初设后，优先输出三个角色构想方案。

禁止直接生成完整角色卡。

禁止因为已有角色卡模板就机械填满字段。

# 4.调研

用户在当前任务中明确提到“调研”时，必须进行外部调研。

优先搜索具有较高人气、知名度或长期影响力的娱乐作品，包括游戏、动画、漫画、小说、电影、电视剧等。

调研关注作品怎样塑造与当前角色相近的人物。

重点观察：

①人物怎样被快速建立起来，例如初登场行为、语言、职业、关系、冲突和视觉印象。

②人物最鲜明的特征是什么，重点寻找能够用一个词、成语、四字词语或短语表达的人物印象。

③人物行为怎样证明其性格，寻找实际场景中的选择和行为，避免只整理设定介绍。

④作品如何处理角色的表里差异，观察公开形象、真实动机、隐藏人格以及关键时刻的选择。

⑤有哪些塑造方式值得借鉴或规避，尤其关注人物是否沦为功能角色、套路角色，或依靠其他人物受苦来衬托其魅力。

调研结果只承担参考作用。

三个角色构想可以采用调研中没有出现的方向。

只要方案本身成立，就可以提出。

# 5.第一次输出：三个角色构想

角色构想属于创意任务。

每次首次构思角色时，输出三个具有明显差异的方案。

方案可以在人物气质、核心动机、隐藏面和人物逻辑上大胆分叉。

已经由用户确认的事实保持一致。

每个方案至少包含：

`高识别度词 + 核心动机 + 隐藏面 + 人物逻辑`

## 5.1 高识别度词

高识别度词由 Skill 主动提出。

它需要直接回答：

“这是个什么样的人？”

优先使用成语、四字词语、描述性短语、社会类型、人格类型、身份称谓、具有明确人物联想的隐喻。

例如：

`道貌岸然`

`天之骄子`

`体面的刀子`

`老好人`

`管家婆`

`亡命之徒`

`刀子嘴豆腐心`

`及时行乐`

`恃才傲物`

高识别度词需要具有生成能力。

看到这个词以后，应当能够继续想象这个角色怎样讲话、怎样处理问题、怎样看待别人、怎样应对冲突。

普通性格词可以使用，但信息量过低时不能单独承担人物塑造。

例如：

`冷静`

`认真`

`执着`

`聪明`

`谨慎`

这类词通常需要进一步提炼。

高识别度词属于本 Skill 的创作辅助信息，目前不作为新的正式角色卡字段。

## 5.2 核心动机

沿用当前《角色卡字段口径》：

“无论外部处境如何变化，持续驱动角色选择的根本需求。”

尽量用一句话写清这个角色真正想得到什么、守住什么或避免什么。

例如：

`减轻其他人的痛苦。`

核心动机需要能够解释角色在不同情境中的选择。

它应当可以继续产生具体行为。

人物经历、主题概括和性格评价不能代替核心动机。

## 5.3 隐藏面

沿用当前《角色卡字段口径》：

“这个角色不为人知的一面。”

优先使用一个高密度词或短语概括。

例如：

`傲慢`

`怠惰`

`冷漠`

`弑杀`

`依赖`

`温柔`

`胆怯`

后面可以附一段简短解释，说明这个词在当前角色身上的实际含义。

隐藏面需要能够继续产生人物行为。

是否存在戏剧性秘密，由角色本身决定。

禁止为了制造反转强行添加悲惨过去、黑暗人格或秘密身份。

## 5.4 人物逻辑

人物逻辑用于解释：

`高识别度词 + 核心动机 + 隐藏面`

如何组成同一个人。

重点描述：

①她习惯怎样理解事情。

②她最容易注意什么。

③发生冲突时，她通常优先保护什么。

④哪些行为对她而言属于自然反应。

人物逻辑需要能够支持后续公开特质和行为习惯的生成。

这一阶段只建立人物逻辑，暂不展开完整任务规则。

# 6.三个方案的差异要求

三个方案必须具有真实的创作差异。

禁止把同一个方案换三个形容词、只改变隐藏面名称、只改变措辞，或用轻微程度差异伪装成三个方向。

允许三个方案像三种不同的人，只要它们都能从用户原始设定合理发展出来。

例如，同一个寡言猎魔人可以发展为：

`嫉恶如仇`

`悲天悯人`

`嗜血成性`

三个方向可以拥有相似的表面行为，却拥有完全不同的核心动机和隐藏面。

# 7.用户选择后的处理

用户可以选择某个方案、修改方案、混合多个方案、否定全部方案或提出新的方向。

Skill 根据用户选择更新当前已确认的人物设计。

用户选择方案后，只确认已经讨论到的内容。

禁止自动生成完整角色卡。

# 8.“继续下一步”的处理

角色设计没有固定到可以机械推进的唯一下一步。

如果用户明确指定内容，例如：

`继续写公开特质`

`补人物逻辑`

`设计她的行为习惯`

`重新想隐藏面`

直接完成指定任务。

如果用户只说：

`继续`

`继续下一步`

`往下`

`接着做`

需要先确认用户所说的“下一步”具体指什么。

根据当前已经完成的内容，简短列出当前合理的后续选项。

例如：

`目前可以继续做公开特质、行为习惯，或者继续调整人物逻辑。你要先做哪一个？`

确认具体目标后，只完成该项。

“继续下一步”不能被解释为“补全角色卡”。

# 9.公开特质设计

当用户要求设计公开特质时，沿用《角色卡字段口径》：

“玩家初始就知道、会影响派遣判断的稳定行为倾向。”

公开特质名称本身必须具有足够的信息量。

它需要能够让玩家看到名称时大致理解这项特质。

优秀方向例如：

`体面的刀子`

`全才`

`令行禁止`

`平民优先`

名称之后再用具体描述说明它如何表现。

公开特质的生成过程：

`已有角色设计 → 找到长期稳定的行为共同点 → 提炼名称 → 写具体表现`

禁止直接从用户原案里随便抽一个普通形容词作为名称。

例如：

角色设定为：

“所有与亡灵或叛教者有关的任务都会接下，报酬可有可无。”

概括成：

`执着`

属于低质量提炼。

“执着”没有表达角色执着的对象、态度以及人物特色。

公开特质需要完成创意提炼。

名称与后续描述必须准确对应。

# 10.行为习惯

当用户要求继续塑造具体表现时，优先设计行为习惯。

行为习惯用于让已经建立的人物逻辑真正出现在场景中。

可以设计：

①交流习惯：角色怎样提问、回答、打断、沉默或表达意见。

②工作习惯：检查装备、写报告、处理证据、准备任务等固定行为。

③压力反应：遇到失败、危险、争执、等待时自然出现的行为。

④生活习惯：与职业、阶层、价值观和性格有关的日常表现。

⑤对人的习惯：角色怎样对待陌生人、弱者、上级、同伴或讨厌的人。

行为习惯需要能够证明角色是谁。

避免用大量随机癖好制造人物感。

甜食、怕虫、酒量差、睡姿等生活细节只有在确实服务当前人物时才加入。

# 11.人物塑造检查

每完成一个重要设计，可以用以下标准检查：

①高识别度：能否用少量信息迅速认出这个人。

②统一：核心动机、隐藏面、公开表现和行为是否来自同一个人物逻辑。

③生成能力：已有设计能否自然推导出新的场景行为。

④具体：设计能否落实到角色实际会做什么。

⑤区别：角色是否拥有属于自己的判断方式。

发现问题时直接修改当前设计。

无需为了检查而增加额外字段。

# 12.避免机械复述

本 Skill 必须主动完成创作。

用户原案：

`她会接下所有亡灵相关任务，报酬无所谓。`

低质量处理：

`她很执着。`

这种处理只是压缩信息。

需要继续判断她为什么这样、这种行为让她像什么样的人、什么词能够真正统摄这种人格、它与她的核心动机和隐藏面有什么关系。

最终产出的内容需要比原始素材多一步人物理解。

# 13.避免过度创作

创作需要服务当前人物。

禁止为了显得完整而自动增加复杂身世、悲惨过去、隐藏组织、宿敌、恋爱关系、重大阴谋、特殊血统、创伤或反转身份。

这些内容只有在人物设计真正需要或用户明确要求时加入。

角色可以靠性格、职业、价值观和具体行为成立。

# 14.与 guild-today-char-card 的边界

本 Skill 到“人物设计确认”为止。

当用户明确要求：

`写完整角色卡`

`按这个设计制作角色卡`

`转成正式角色卡`

`写入角色卡`

此时进入 `guild-today-char-card` 的职责范围。

正式角色卡制作时，以 `guild-today-char-card` 当前有效版本以及正式策划案字段口径为准。

本 Skill 不自行维护程序字段、完整违抗链规范、全部里档案字段规范、Notion 写入规则、正式版本管理或完整角色卡模板。

这些内容由 `guild-today-char-card` 负责。

如果两个 Skill 的内容产生冲突：

涉及人物创作过程时，以本 Skill 为准。

涉及正式角色卡字段、结构、写入和程序化规则时，以 `guild-today-char-card` 为准。

# 15.默认首次输出格式

首次角色构想保持紧凑。

### 方案A｜高识别度词

**核心动机：**

**隐藏面：**

**人物逻辑：**

### 方案B｜高识别度词

**核心动机：**

**隐藏面：**

**人物逻辑：**

### 方案C｜高识别度词

**核心动机：**

**隐藏面：**

**人物逻辑：**

如果进行了调研，在三个方案之前先输出与本次设计直接相关的调研发现。

调研内容只保留能够帮助当前创作的部分。

三个方案输出完成后停止，等待用户选择、修改或提出其他方向。

# 16.核心判断标准

角色设计过程中始终判断：

`这个词能不能让我迅速知道她是什么样的人？`

`这些行为能不能让我相信她真的会这么做？`

`换一个普通角色以后，这套设计还成立吗？`

如果一项内容谁都能用，它通常还没有完成角色塑造。

如果一个概括词无法准确覆盖后面的具体行为，需要重新提炼。

最终目标是：

先创造一个具体的人，再让这个人进入角色卡。
