# 1.总体边界

①玩家可见信息与后台信息分别维护。

②Task 保存会影响派遣、判定、Result、资产连接与持续后果的信息。

③字段根据当前 Task 实际需要填写。

④Task 保存任务主干与稳定资产引用。

⑤委托报酬记录委托发布时的承诺值。

⑥Result 负责实际结果与持续变化。

⑦程序字段结构化已经确认的 Task 内容。

# 2.基础身份与委托简述

| 字段 | 定义 | 填写要求 |
|---|---|---|
| 任务ID（玩家不可见） | Task 静态资产稳定唯一编号。 | 必填。 |
| 任务名称 | Task 名称与玩家看到的委托标题。 | 必填。 |
| 委托人 | 提出委托的人、组织或群体。 | 必填。 |
| 委托来源 | Task 进入公会的渠道或来源资产。 | 必填。 |
| 委托指定地点 | 委托指定的主要地点或区域。 | 必填。 |
| 后台等级风险（玩家不可见） | 策划对实际风险的后台判断。 | 按任务需要。 |
| 任务有效期限（玩家不可见） | Task 在后台保持有效的期限。 | 按任务需要。 |

# 3.委托详述

| 字段 | 定义 | 填写要求 |
|---|---|---|
| 委托描述 | 玩家收到 Task 时看到的主要委托正文。 | 必填。 |
| 委托目标 | 玩家被明确要求完成的目标。 | 必填。 |
| 委托报酬 | 发布时承诺的任务报酬。 | 必填。 |
| 预计持续时间 | 派遣前预计任务时长。 | 按任务需要。 |
| 公示时间期限 | 玩家被告知的接取、出发或完成期限。 | 按任务需要。 |
| 推荐能力 | 当前委托建议的能力方向。 | 选填。 |
| 初步评估风险 | 玩家派遣前可以看到的风险判断。 | 按任务需要。 |
| 可见情报 | 无需额外成本即可获得的信息。 | 选填。 |
| 可购买 / 可追加获取的情报 | 玩家通过额外成本或明确渠道获得的信息。 | 选填。 |
| 委托方特别说明 / 附加条件 | 委托方向玩家明确提出的附加要求。 | 选填。 |

# 6.生命周期与生成规则

| 字段 | 定义 | 填写要求 |
|---|---|---|
| 唯一性 / 重复生成规则 | Task 是否允许再次生成，以及对应限制。 | 按任务需要。 |
| 出现规则 | Task 什么时候具备生成或发布资格。 | 必填。 |
| 过期规则 | 时间经过后 Task 的任务专属过期规则。 | 选填。 |
| 失效规则 | 世界、人物或其他状态造成的 Task 失效规则。 | 选填。 |
| 进行中规则 | Task 进入 IN_PROGRESS 后的任务专属规则。 | 选填。 |
| 放弃规则 | 当前 Task 的主动放弃规则或任务专属例外。 | 按任务需要。 |
| 特例 | 其他生命周期字段无法承载的 Task 专属规则。 | 选填。 |
| 前置解锁条件 | Task 出现前需要满足的已有状态条件。 | 选填。 |

# 7.后台判定与资产连接

| 字段 | 定义 | 填写要求 |
|---|---|---|
| 前置解锁事件 | 直接参与 Task 解锁的 Event 引用。 | 选填。 |
| 判定输入 | Task 最终结算实际读取的信息。 | 必填。只列当前 Task 实际使用的输入。 |
| 判定数值组合 | 当前 Task 实际使用的数值判断、阈值或组合。 | 按任务需要。 |
| 特殊组合 | 当前 Task 条件下成立的角色、队伍或条件组合规则。 | 选填。 |
| 结果组引用 | 当前 Task 对应的 Result Group 稳定引用。 | 必填。 |
| 最终判定时机 | Task 进入最终 Result 选择的时机。 | 必填。 |
| 后续可解锁事件 | Task 可能连接的后续 Event。 | 选填。 |
| 关联任务 | 与当前 Task 存在明确内容关联的其他 Task。 | 选填。 |

# 8.判定输入解释

`判定输入` 可以读取当前 Task 实际使用的正式信息，例如：

`角色能力`

`职业与经历`

`角色状态`

`角色特质`

`角色行为规则`

`行为优先级`

`角色关系`

`角色特殊组合`

`参与结算的任务情报`

`任务专属准备`

`世界状态`

`时间状态`

`其他已经确认的正式资产字段`

会直接改变任务执行或 Result 的信息进入判定输入。

---

# 9.特殊组合解释

`Character.特殊组合` 表示跨多个 Task 稳定成立的人物组合规则。

`Task.特殊组合` 表示当前 Task 条件下成立的任务专属组合规则。

Task 特殊组合可以由：

`角色`

`队伍`

`地点`

`任务目标`

`环境`

`任务特殊条件`

共同形成。

真实 Task 出现其他准备类型时，根据实际内容确认正式承载字段。
