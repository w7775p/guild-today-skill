# 1.总体边界

①玩家可见信息与后台信息分开维护。

②任务卡只记录会影响判定、Result、报告或持续后果的信息。

③字段允许留空或填写“无”。

④任务卡保存任务主干与稳定引用；Event、Result 正文由对应资产维护。

⑤委托报酬是发布时承诺；实际奖励、损失与状态变化由具体 Result 定义。

⑥程序字段用于结构化已确认内容。

# 2.基础身份与委托简述

| 字段 | 定义 | 填写要求 |
|---|---|---|
| 任务ID（玩家不可见） | 任务静态资产的稳定唯一编号。 | 必填。项目级唯一；确定后尽量不改。 |
| 任务名称 | 任务名称与玩家通常看到的委托标题。 | 必填。简短、可识别。 |
| 委托人 | 提出委托的人、组织或群体。 | 必填。填写发布时玩家可知身份。 |
| 委托来源 | 任务进入公会的渠道或来源资产。 | 必填。需要追踪时使用稳定引用。 |
| 委托指定地点 | 委托指定的主要目标地点或区域。 | 必填。以玩家可知信息填写。 |
| 后台等级风险（玩家不可见） | 策划对任务真实风险的后台判断。 | 按任务需要填写。 |
| 任务有效期限（玩家不可见） | 任务在后台保持有效的期限。 | 按任务需要填写。 |

# 3.委托详述（玩家可见信息）

| 字段 | 定义 | 填写要求 |
|---|---|---|
| 委托描述 | 玩家收到任务时看到的主要委托正文。 | 必填。只包含当时可知信息。 |
| 委托目标 | 玩家被明确要求完成的目标。 | 必填。能直接回答“这趟任务要做什么”。 |
| 委托报酬 | 发布时向公会承诺的报酬。 | 必填。实际结算由具体 Result 定义。 |
| 预计持续时间 | 派遣前提供给玩家的预计任务时长。 | 按任务需要填写。 |
| 公示时间期限 | 玩家被告知的接取、出发或完成期限。 | 按任务需要填写。 |
| 推荐能力 | 委托信息建议的能力方向。 | 选填。提示项。 |
| 初步评估风险 | 玩家派遣前能够看到的风险判断。 | 按任务需要填写。基于当前可知信息。 |
| 可见情报 | 无需额外成本即可获得的补充信息。 | 选填。保留服务任务判断的信息。 |
| 可购买 / 可追加获取的情报 | 玩家通过额外成本或已定义方式获得的附加信息。 | 选填。 |
| 委托方特别说明 / 附加条件 | 委托方向玩家明确提出的附加要求。 | 选填。硬性派遣资格写入“特殊派遣要求”。 |

# 4.里档案

| 字段 | 定义 | 填写要求 |
|---|---|---|
| 任务真相 | 策划掌握的任务真实情况。 | 必填。只写任务需要的内容。 |
| 核心矛盾 | 任务中真正影响取舍与结果的主要矛盾。 | 按任务需要填写。 |
| 隐藏风险 / 未公开变量 | 玩家派遣前不知道、且会实际影响任务的关键变量。 | 选填。最多 3 点。 |
| 设计目的 | 说明这张任务主要承担或验证什么设计作用。 | 选填。简短、具体。 |

---

# 5.派遣规则

| 字段 | 定义 | 填写要求 |
|---|---|---|
| 最少派遣人数 | 允许出发的最低人数。 | 必填。 |
| 最多派遣人数 | 允许出发的最高人数。 | 必填。 |
| 派遣限制说明 | 说明本任务为何存在人数或其他限制。 | 选填。 |
| 特殊派遣要求 | 除人数外必须满足的出发条件。 | 选填。 |

---

# 6.生命周期与生成规则

| 字段 | 定义 | 填写要求 |
|---|---|---|
| 唯一性 / 重复生成规则 | 任务是否允许再次生成，以及存在什么限制。 | 按任务需要填写。 |
| 出现规则 | 任务什么时候有资格生成或发布。 | 必填。只写实际存在的条件。 |
| 过期规则 | 因时间经过导致任务失去有效性的规则。 | 选填。 |
| 失效规则 | 因世界、人物或其他状态变化导致任务失效的规则。 | 选填。 |
| 进行中规则 | Task 进入 IN_PROGRESS 后存在的任务专属规则。 | 选填。 |
| 放弃规则 | 当前任务的主动放弃规则或任务专属例外。 | 按任务需要填写。 |
| 特例 | 其他生命周期字段无法承载的任务专属规则。 | 选填。 |
| 前置解锁条件 | 任务出现前必须满足的状态条件。 | 选填。只写实际条件。 |

---

# 7.后台判定与资产连接

| 字段 | 定义 | 填写要求 |
|---|---|---|
| 前置解锁事件 | 直接参与任务解锁的 Event 引用。 | 选填。稳定引用。 |
| 任务内事件引用 | 任务执行期间可能发生的独立 Event 引用。 | 选填。只保存稳定 Event 引用，不复制事件正文；只有真实任务需要独立 Event 时填写。 |
| 判定输入 | 任务最终结算实际读取的信息。 | 必填。只列当前任务实际使用的输入。 |
| 判定数值组合 | 当前任务实际使用的数值判断、阈值或组合。 | 按任务需要填写。 |
| 特殊组合 | 特定角色、队伍或条件组合触发的额外规则。 | 选填。 |
| 结果组引用 | 当前 Task 对应的 Result Group 稳定引用。 | 必填。 |
| 最终判定时机 | 任务什么时候进入最终 Result 选择。 | 必填。 |
| 后续可解锁事件 | 任务可能关联的后续 Event。 | 选填。 |
| 关联任务 | 与当前任务存在明确内容关联的其他 Task。 | 选填。 |
