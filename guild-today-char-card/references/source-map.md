# 《今日公会照常营业》角色 Skill 真源映射

本文件定义：

`去哪里读取正式信息`

以及：

`每个真源负责裁决什么`

`SKILL.md` 负责工作方法。

## v5.1 底稿与读取优先级

①用户当前明确决定优先；用户指定的人工修订稿是本轮角色内容底稿。未被修改的事实由对应领域真源补足。

②当前角色池用于取得关联事实与未另行指定的角色正文。发布时间、文件名版本号或模型旧输出不能自动覆盖人工修订稿。

③同一任务内复用已完整读取且仍有效的资料。涉及新的事实、冲突或外部写入时，重新读取相关来源；写入前始终核对目标最新内容。

④仅做排版或发布已有完整底稿时，读取目标格式与直接相关资料即可。创作、重构和字段判断按下列领域职责读取。

⑤本轮包含占位或推测内容时保留标记，不因进入角色池而改变确认状态。

# 9.冲突裁决

发生冲突时，先确定信息属于哪个领域。

使用：

`项目级结论 → 《当前项目真源》`

`角色字段规则 → 《角色卡字段口径》`

`正式角色事实 → 《当前角色池》`

`任务领域规则 → 《任务卡》`

`具体任务事实 → 对应正式任务资产`

`事件领域规则 → 《事件卡》`

`具体事件事实 → 对应正式事件资产`

`Result 领域规则 → 《结果组卡》`

`具体 Result 事实 → 对应正式 Result / 结果资产`

`公共规则 → 《规则表》或当前明确指定的对应公共真源`

用户当前明确作出的新设定或修改决定，作为当前任务中的最新事实。

同一领域存在多个均声称为当前正式、现有资料又无法判断有效版本的来源时：

`指出具体冲突 → 保留受影响部分 → 继续完成其他部分`
